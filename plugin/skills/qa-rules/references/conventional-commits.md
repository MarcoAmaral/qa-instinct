# Conventional Commits Rules & Guidelines

Scope: commits the AI makes in this repository (the project that installed the package).

- Start every message with a Conventional Commits type: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test` or `chore`.
- One concept per commit; a message that needs "and" is two commits.
- Mark a breaking change with `!` after the type or a `BREAKING CHANGE:` footer.

Detail: the `qa-reference` skill's `references/repo-conventions.md`
